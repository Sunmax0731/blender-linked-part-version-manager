# v0.1.0-alpha.2

## 種別

Prerelease / alpha

## 内容

- Add-on / Windows companion の実装バージョンを `0.1.1` に更新した。
- `Linked Parts` パネルで `Scan Current Links`、editable registry list、`Save Registry` を使い、JSON を直接編集しなくても Part Registry を生成・編集・保存できるようにした。
- `Add File Candidate`、`Preview Link`、`Link Candidate` を追加し、Explorer / Blender file selector で選んだ `.blend` を候補化して明示操作で Blender tree へ Link できるようにした。
- GUI 生成候補の初期値を `owner=unassigned`、`source.type=local`、`source.root=.`、`versionRef=local`、`updatePolicy=manual` に固定した。
- Link 操作は dry-run と明示実行に分け、現在の `.blend` を自動保存しない方針を維持した。
- Blender 表示言語が日本語の場合に `Linked Parts` パネル、主要 operator、ボタン、status / report message を日本語表示する `ja_JP` UI 翻訳を追加した。
- README、AGENTS、SKILL、docs、TODO、Issues、QCDS、release evidence を `v0.1.0-alpha.2` 向けに同期した。

## 検証

- `cmd.exe /d /s /c npm test`
- Windows companion `--version` / settings save / installer dry-run
- Blender 5.1.1 CLI smoke from `D:\SteamLibrary\steamapps\common\Blender\blender.exe`
- Blender add-on import smoke
- Blender add-on `register()` / `unregister()` smoke
- Python unit test confirmed GUI registry candidate defaults and linked library scan helper behavior.
- Python unit test and Blender 5.1.1 CLI confirmed Japanese UI translation table coverage and `pgettext_iface` resolution for core labels.

## 既知の制約

- GUI registry editing と日本語 UI 表示の Blender 実機操作は次回手動確認で `Scan Current Links`、`Save Registry`、`Add File Candidate`、`Preview Link`、`Link Candidate`、表示言語切替を通しで確認する。
- Auto Reload は保存済み linked `.blend` のファイル更新時刻を監視する。別 Blender ウィンドウの未保存編集は `.blend` に書き込まれていないため、Blender Link reload では反映できない。
- `local-dirty` / `conflict-risk` / `broken-link` 相当の blocked part は自動更新対象から外す。
