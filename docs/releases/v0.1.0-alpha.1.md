# v0.1.0-alpha.1

## 種別

Prerelease / alpha

## 内容

- Blender 4.2 以降向け add-on shell を追加。
- Part Registry validator、sync plan、dry-run report、Git / local adapter contract を実装。
- Blender Sidebar の `Linked Parts` パネルで registry validation、sync preview、reload dry-run、safe reload を実行可能にした。
- 保存済み linked `.blend` を一定間隔で監視する `Start Auto Reload` / `Stop Auto Reload` を追加。safe な対象だけを reload する。
- Windows companion launcher で registry validation、status preview、settings 保存、installer dry-run を実行可能にした。
- 手動テスト用の `integration/character_integration.blend` と部位別 `.blend` fixture を追加し、`blender-linked-part-version-manager-fixtures.zip` として配布対象にした。
- Manual test で検出した reload 対象 path 不一致を修正し、registry の `parts/...` と integration `.blend` の `//../parts/...` linked library を照合できるようにした。
- `npm test` に docs check、Python unit test、Windows runtime gate、release packaging、artifact check を統合。
- QCDS、installation guide、user guide、manual test、strict manual test addendum、release evidence を更新。

## 検証

- `npm test`
- Windows local executable launch
- Windows settings save
- Windows installer dry-run launch
- Blender 5.1.1 CLI smoke from `D:\SteamLibrary\steamapps\common\Blender\blender.exe`
- Fixture integration file links Hair、Body、Face、Accessories part `.blend` files.
- User manual test on Blender 5.1.1 confirmed install / fixture display / registry validation / sync preview / Preview Reload / Reload Safe Links.
- User manual test confirmed saved Hair source edits are reflected after `Reload Safe Links`.

## 既知の制約

- Auto Reload は保存済み linked `.blend` のファイル更新時刻を監視する。別 Blender ウィンドウの未保存編集は `.blend` に書き込まれていないため、Blender Link reload では反映できない。
- `local-dirty` / `conflict-risk` / `broken-link` 相当の blocked part は自動更新対象から外す。
