# v0.1.0-alpha.3

## 種別

Prerelease / alpha

## 内容

- Add-on / Windows companion の実装バージョンを `0.1.2` に更新した。
- `Preview Integrate` / `Integrate Link` を追加し、選択中の linked `.blend` を確認ダイアログ後に current file の local data へ統合できるようにした。
- `Integrate Link` は不可逆操作、対象 linked file、出力先 current file を確認ダイアログで表示し、cancel 時は `.blend`、Link 状態、Part Registry を変更しない。
- 統合結果と warning を `Report Path` に `operation=integrate-linked-library` の JSON report として保存する。
- `Add File Candidate` / `Preview Link` が source `.blend` の collection / object 候補を inspection し、`ref` collection へ暗黙 fallback しないようにした。
- README、AGENTS、SKILL、docs、TODO、Issues、QCDS、release evidence を `v0.1.0-alpha.3` 向けに同期した。

## 既知の制約

- Link integration の Blender 実機操作は次回手動確認で `Preview Integrate`、`Integrate Link` cancel、コピー fixture での確認あり実行を確認する。
- GUI registry editing、Link Candidate target selection、日本語 UI 表示の Blender 実機操作は次回手動確認で `Scan Current Links`、`Save Registry`、`Add File Candidate`、`Preview Link`、`Link Candidate`、表示言語切替を通しで確認する。
- Auto Reload は保存済み linked `.blend` のファイル更新時刻を監視する。別 Blender ウィンドウの未保存編集は `.blend` に書き込まれていないため、Blender Link reload では反映できない。
- `local-dirty` / `conflict-risk` / `broken-link` 相当の blocked part は自動更新対象から外す。
