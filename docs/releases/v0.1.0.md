# v0.1.0

## 種別

正式リリース / stable

## 内容

- `v0.1.0-alpha.3` の配布内容を正式リリース化した。
- Blender add-on / Windows companion の実装バージョンは `0.1.2` を維持する。
- Part Registry の scan / edit / save、`.blend` file candidate 追加、preview first の Link / Reload / Integrate、Auto Reload、Windows companion、手動テスト fixture を配布対象に含める。
- `Link Candidate` は source `.blend` の collection / object 候補を inspection し、`ref` / `reference` / camera / light / floor 系を暗黙選択しない。
- 読み込んだ collection はチェックボックスで確認し、チェック済み collection だけを複数 Link 対象にできる。
- source `.blend` 内の nested Blender Link は `sourceLinkedLibraries` / `indirectLinkedLibraries` として report し、依存 library の local 化や自動保存は行わない。
- Reference 用画像、ライト、カメラは型付きの明示候補として report し、floor / helper 系は除外理由を report する。
- linked file 統合は `Preview Integrate` / `Integrate Link` に分け、確認ダイアログ、不可逆性表示、report 保存、`.blend` 自動保存なしを維持する。
- README、installation guide、user guide、manual test、QCDS、release evidence、TODO、Issues を正式リリース向けに同期した。

## 既知の制約

- Blender UI 上の GUI registry editing、collection checkbox multi-link、indirect linked library report、Link target type expansion、日本語 UI 表示、Link integration confirmation は次回 manual pass で通し確認する。
- Auto Reload は保存済み linked `.blend` のファイル更新時刻を監視する。別 Blender ウィンドウの未保存編集は `.blend` に書き込まれていないため、Blender Link reload では反映できない。
- `local-dirty` / `conflict-risk` / `broken-link` 相当の blocked part は自動更新対象から外す。
- Link integration は linked datablock を local data に変える不可逆操作であるため、確認あり実行はコピーした fixture で行う。
