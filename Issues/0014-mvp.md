## Context

MVP後の機能実装として、Add-on画面上でExplorerからファイルを選択し、その選択内容をBlenderのツリー上に反映してLink化する仕組みを整備する。Blenderのツリー側で直接操作する設計ではなく、Add-on UIを起点にしたファイル選択と反映を前提にする。README、AGENTS、SKILL、docs、TODO、Issues を同じ変更単位で更新する repo 方針を守り、Blender アドオン側と Windows companion 側の責務分離を維持する。

## Acceptance Criteria

- [x] Add-on画面上からExplorerで対象ファイルを選択し、Link化対象として扱える。
- [x] 選択したファイルがBlenderのツリー上に反映される導線が、既存設計と責務分離に沿って実装されている。
- [x] 開発ドキュメント、マニュアル、README.md が実装内容に追従して更新されている。
- [x] TODO.md と Issues の状態が、完了済み作業と残作業を判別できる状態に整理されている。
- [x] リリース前確認に必要な検証項目と既知の手動確認範囲が docs に明記されている。
